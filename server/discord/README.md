# ИНФРАСТРУКТУРА DISCORD-СЕРВЕРА WARLINK

Комплекс ботов для полной интеграции Discord-сообщества с игровым шлюзом и приложением WarLink.

## 1. Архитектура ботов

1. **WarLink Core Bot** (`bot_core.py`):
   - **Центр тикетов поддержки (Staff Desk)**: Слушает события Redis Pub/Sub (`tickets:new`) при создании тикетов в клиенте WarLink. Автоматически создает ветку в закрытом форуме `#тикеты-входящие`, скачивает архив логов пользователя `logs.tar.gz`, прикрепляет карточку системы и ошибку. Любое сообщение администратора в ветке отправляется прямо в приложение игроку через WarLink API (`/api/v1/admin/tickets/:id/reply`). Кнопка `[Решено / Закрыть]` закрывает тикет в базе.
   - **Связка аккаунтов**: В канале `#привязка-warlink` размещает интерактивную кнопку. По нажатию открывается модальное окно для ввода 6-значного кода из приложения WarLink, после чего бот мгновенно выдает роль игрока и почетную роль `Спонсор WarLink` (при наличии доната).
   - **Инфраструктурный мониторинг**: Раз в 30 секунд обновляет статусное Embed-сообщение в канале `#мониторинг` (пинг до Стокгольма, статус шлюза Hysteria 2, занятые слоты 38/100, версия клиента).

2. **WarLink Status Bot [Стокгольм]** (`bot_status.py`):
   - Размещается в самом верху сайдбара участников Discord под ролью `🟢 СИСТЕМНЫЙ СТАТУС`.
   - В кастомном статусе Rich Presence и никнейме отображает живой пинг и загрузку слотов:
     `🟢 19ms | 38/100 слотов` (ник: `[🟢 19ms] Стокгольм`).
   - При отказе сети автоматически переключается в `[🔴 OFFLINE] Стокгольм`.

## 2. Пошаговая настройка в Discord Developer Portal

1. Перейдите в [Discord Developer Portal](https://discord.com/developers/applications).

### Создание WarLink Core Bot:
2. Нажмите **New Application** -> назовите `WarLink Core`.
3. Перейдите во вкладку **Bot**:
   - Нажмите **Reset Token** и скопируйте токен в `DISCORD_CORE_BOT_TOKEN`.
   - В блоке **Privileged Gateway Intents** ОБЯЗАТЕЛЬНО включите:
     - `SERVER MEMBERS INTENT` (для выдачи ролей игрокам и спонсорам).
     - `MESSAGE CONTENT INTENT` (для чтения ответов администратора в тредах тикетов).
4. Перейдите во вкладку **OAuth2 -> URL Generator**:
   - В блоке **Scopes** выберите: `bot`, `applications.commands`.
   - В блоке **Bot Permissions** выберите: `Administrator` (или Manage Roles, Manage Channels, Read Messages, Send Messages, Attach Files, Manage Threads, Read Message History).
   - Скопируйте полученную ссылку и добавьте бота на свой сервер.

### Создание WarLink Status Bot (Стокгольм):
5. Нажмите **New Application** -> назовите `WarLink Stockholm`.
6. Во вкладке **Bot**:
   - Нажмите **Reset Token** и скопируйте токен в `DISCORD_STATUS_BOT_TOKEN`.
7. Во вкладке **OAuth2 -> URL Generator**:
   - Scopes: `bot`.
   - Bot Permissions: `Change Nickname`.
   - Добавьте бота на свой сервер.

## 3. Настройка Discord-сервера

### Режим разработчика (для получения ID):
В Discord: *Настройки пользователя -> Расширенные -> Включить «Режим разработчика»*. Теперь при правом клике на любой канал, роль или сервер доступен пункт *«Копировать ID»*.

### Иерархия ролей (Сверху вниз):
1. `🟢 СИСТЕМНЫЙ СТАТУС` (В настройках роли включить: *«Показывать участников с этой ролью отдельно от остальных участников»*). Выдать боту `WarLink Stockholm`.
2. `🛡️ Администратор` (Полный доступ, видит закрытые тикеты).
3. `⭐ Спонсор WarLink` (Цветной никнейм, доступ к закрытому чату спонсоров).
4. `⚔️ Боец WarLink` (Роль верифицированного пользователя).
5. `@everyone`

### Настройка каналов и прав:
- **`#тикеты-входящие`** (Тип: **Форум / Forum Channel**):
  - Приватный канал: доступ только для роли `🛡️ Администратор` и бота `WarLink Core`.
- **`#привязка-warlink`** (Текстовый канал):
  - `@everyone`: Просмотр сообщений — Да, Отправка сообщений — **НЕТ**.
- **`#мониторинг`** (Текстовый канал):
  - `@everyone`: Просмотр сообщений — Да, Отправка сообщений — **НЕТ**.

## 4. Развертывание на боевом VPS

1. Перейдите в каталог проекта на VPS:
   ```bash
   cd /opt/warlink-server/discord
   ```
2. Создайте виртуальное окружение Python:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Скопируйте конфигурацию и заполните ID и токены:
   ```bash
   cp .env.example .env
   nano .env
   ```
4. Установите и запустите systemd-службу:
   ```bash
   cp warlink-discord.service /etc/systemd/system/
   systemctl daemon-reload
   systemctl enable --now warlink-discord.service
   systemctl status warlink-discord.service
   ```
5. В Discord-сервере администратор пишет слеш-команду:
   ```text
   /setup_panels
   ```
   Бот автоматически опубликует панель привязки с кнопкой в канале `#привязка-warlink` и инициализирует Live Embed в канале `#мониторинг`.
